# 12 · 查词弹卡设计（写作台词卡）

> **状态（2026-10-31 定稿）：本文已全文并入 `11-rewrite-spec.md` §八，不再单独维护。
> 实现一律以 11 号文档为准，本文仅供追溯。**

> 本文是 11-rewrite-spec.md 中 FR-701 / FR-1201 / FR-1204"词卡"部分的详细设计，
> 验收按 §6 的 AD 清单逐条打勾。参考基线：浏览器扩展现有实现
> （划词词卡、ECDICT 词典链路、web/word-popup.js），但交互按写作台场景重新裁剪。
>
> 定位：把"写作中遇到没把握的词"变成一次 **3 秒内的学习动作**——查到 → 看懂 →
> 收藏（带着你写的句子）→ 之后复习时挖的就是这句。它是学习闭环（FR-12xx）的入口。

---

## 1. 目标与边界

**一句话**：写作台和词表页里，双击或划选英文单词，原地弹出释义卡，一键收藏进生词本。

对齐 11 §1.3 判断标准：本功能服务 ②"学会"（查词收藏的入口）与 ①"写对"（用词拿不准时当场确认）。

**做什么**：单词查询（词典优先）、短语搭配解释（≤4 词）、一键收藏（自动带所在句）、单词朗读、已收藏状态展示。

**不做什么（明确取舍）**：

| 不做 | 理由 |
| --- | --- |
| 划选整句弹翻译卡 | 写作台的整段回译已覆盖；且与编辑器光标操作打架 |
| 多家在线词典聚合 | 扩展的经验教训：协议杂、不稳定、易被封；收敛为 ECDICT + 模型兜底两极（对齐 DR-7） |
| 卡片内做笔记/换词库/编辑释义 | 卡片只读 + 收藏；管理动作去词表页，保持卡片 3 秒内可离开 |
| 中文词查询 | 查词只服务英文写作语言；写作语言为中文（语言对反转）时不触发（对齐 FR-206 精神） |

---

## 2. 触发（什么时候弹）

> 触发体系直接沿用浏览器扩展划词翻译的成熟设计（划选即弹 / 图标确认 / 修饰键 / 触发延迟 /
> 自动收起），按"编辑器场景"裁剪：砍掉与写作光标操作打架的模式，保留三种可切换模式 +
> 一个固定入口。默认值与扩展一致 = **划选即弹**。

### 2.1 三种触发模式（设置页可切换，刷新后保留）

| 模式 | 行为 | 适合谁 |
| --- | --- | --- |
| 划选即弹（direct，**默认**） | 双击单词或划选 1–4 词，鼠标松开即弹卡 | 与扩展阅读体验一致，"选中就要查" |
| 浮标确认（icon） | 选中后只在选区旁显示一个小浮标按钮，**点浮标才弹卡** | 写作中经常选中文字做替换/删除的人——选区本身不再触发查询，零打扰 |
| 修饰键（modifier） | 按住 `Alt`（可改 Ctrl/⌘）+ 划选才弹卡 | 键盘流；平时完全不干扰 |

### 2.2 所有模式共用的固定规则

| 动作 | 行为 |
| --- | --- |
| 单击 | **三种模式下都永不弹**——单击是光标定位的高频操作，误触即毁掉功能 |
| 划选 ≥5 个词 | 不弹（视为句子，回译已覆盖） |
| 右栏中文 / 写作语言为中文 | 不弹（对齐 FR-206 精神） |
| 词表页搜索框 | 输入词 + 回车/按钮 → 在固定位置弹卡（不受模式影响） |
| 400px 窄屏 | 长按选词出系统选区 → 按当前模式处理；卡片宽度自适应（≤320px，AD-8） |
| 触发延迟 | 划选即弹模式加 200ms 选区落定延迟（沿用扩展"触发延迟"）：替换式选中（选完立刻打字）不闪卡 |
| 自动收起 | 点空白 / `Esc` / 滚动 / 开始输入 / 切换段落——任一即关（沿用扩展"自动收起"） |
| 自动朗读 | 设置开关，默认关；开启后弹卡立即朗读该词，关闭时仅点朗读按钮发声（沿用扩展"自动朗读"） |

### 2.3 不移植的扩展模式及理由

| 扩展模式 | 处置 | 理由 |
| --- | --- | --- |
| 悬停触发（hover） | 不做 | 编辑器里鼠标掠过就查询，写作场景纯干扰；SDK 阅读场景（P6）再评估 |
| 右键菜单（contextMenu） | 不做 | 需覆盖编辑器原生右键（拼写检查/粘贴），成本高收益低 |
| 圆点（dot） | 并入浮标 | 与 icon 同型，二选一足够 |
| 多套自定义方案（quick-translation） | 不做 | 单人写作台用不上多方案；三种模式 + 固定入口已覆盖 |

**预处理规则**（弹卡前执行）：

1. 选中内容清洗：去首尾标点、统一小写用于查询（展示保留原样）；
2. 纯数字、单个标点、纯符号 → 不弹；
3. 连字符词（`state-of-the-art`）→ 整体查询，失败再去连字符查；
4. 同一词 300ms 内重复触发 → 复用已有卡片，不发请求；
5. 会话内查过的词 → 前端 session 缓存直接命中（词库查询便宜，但保证一致体验）。

## 3. 卡片内容（弹什么）

**词典态（ECDICT 命中，目标 <100ms）**：

```text
┌────────────────────────────────┐
│ recall   /rɪˈkɔːl/   v. n.     │
│ [CET4] [考研] [常用词]           │ ← 考纲/词频标签（ECDICT tag/collins/bnc 字段）
│ v. ① 回忆起；回想起              │
│    ② 召回；收回                  │
│ n. ③ 记忆力；召回               │
│ ⓘ 查询的是 recalled —— 原形 recall │ ← 仅当词形还原生效时显示
│ ────────────────────────────── │
│ 🔊 朗读    ☆ 收藏               │
└────────────────────────────────┘
```

**在线态（ECDICT 未命中 → 模型解释）**：

```text
┌────────────────────────────────┐
│ gerrymander                     │
│ ⓘ 在线解释（AI 生成，仅供参考）    │ ← 来源必须标注
│ v. 为选举利益不公正地划分选区      │
│ e.g. The district was gerrymandered in 2020. │
│ ────────────────────────────── │
│ 🔊 朗读    ☆ 收藏               │
└────────────────────────────────┘
```

- 拼写错误的词走同一通道，模型提示词要求先指出"可能是 XXX 的拼写错误"再给释义；
- **短语态**（划选 2–4 词）：给搭配解释 + 一个例句，同样标注在线来源；
- 两种来源共用同一张卡，只是内容字段与来源标注不同。

**已收藏态**：收藏按钮变为不可再点的状态行：

```text
│ ✓ 已收藏 · 写作中用过 3 次       │
```

卡上**只加不减**：取消收藏去词表页管理，避免误删学习资产。

**字段与来源**：

| 字段 | 词典态来源 | 在线态来源 |
| --- | --- | --- |
| 词头 / 音标 / 词性 / 多条释义 / 考纲标签 | ECDICT 精简库（embed，约 3000 高频词，DR-6） | — |
| 释义 + 例句 + 拼写纠错提示 | — | 模型（经网关，§11 号文档 §7.6） |
| 词形还原提示 | 服务端统一词形还原器 | 同左 |
| 已收藏状态 / 使用次数 | `words` 表按访客查询 | 同左 |

## 4. 交互（怎么弹、怎么关）

| 项 | 规则 |
| --- | --- |
| 位置 | 锚定选区，优先在下方 8px；空间不足翻转到上方；左右夹紧在编辑器容器内，不溢出视口 |
| 非模态 | 弹卡不阻塞写作，可继续打字 |
| 关闭 | 点空白、`Esc`、滚动、切换段落、开始输入——任一即关 |
| 加载 | ECDICT 命中几乎即时；走模型 >150ms 时卡内显示骨架（六态之"加载"）；失败卡内给"没查到 + 重试"（六态之"失败"） |
| 朗读 | 浏览器 `speechSynthesis`（en-US 优先），零服务端成本；不支持的环境按钮置灰 |
| 收藏中 | 点击收藏 → 按钮进入加载态 → 成功变已收藏态；失败卡内提示可重试 |

## 5. 数据与后端

**查询链**（对齐 11 §7.6 网关纪律）：

```text
前端 session 缓存 → GET /api/dict/:word
                     → 服务端内存缓存（FR-1101）
                     → ECDICT embed 查询（命中即返回，source=ecdict）
                     → 模型兜底（source=model；限频 10 次/分钟/访客；
                        结果写回内存缓存，相同词第二次不再打模型）
```

**限频与配额**：查词**不计翻译配额**（FR-604 不受影响）；模型兜底单独限频（默认 10 次/分钟/访客，环境变量可调），超限返回 429 + 卡内"稍后再试"。

**响应结构**（`GET /api/dict/:word`）：

```jsonc
{
  "word": "recall",              // 归一化查询词
  "query": "recalled",           // 原始选中词（与 word 不同时，前端显示词形还原提示）
  "phonetic": "/rɪˈkɔːl/",
  "pos": "v. n.",
  "senses": [ { "pos": "v.", "def": "回忆起；回想起" } ],
  "tags": ["cet4", "ky"],        // 考纲标签，可空
  "source": "ecdict",            // ecdict | model
  "example": null,               // 仅 model 态
  "collected": { "yes": true, "useCount": 3 }   // 按当前访客查 words 表
}
```

**收藏**（FR-1201 落地点）：`POST /api/words`，`context_sentence` = **词所在的完整句子**——

- 提取规则：从选区位置向前、向后找最近的句末标点（`.` `?` `!`），句长截断上限 300 字符；找不到句末标点时取整段；
- 幂等：同访客同词重复收藏返回已有记录（不报错、不重复建行），卡片据此显示已收藏态；
- 词表页搜索框发起的收藏允许 `context_sentence` 为空——复习时该词退化为"词 → 释义"卡（FR-1204 兼容）。

**隐私**：查询行为本身不落库（NFR-6）；只有点收藏才写入 `words` 表片段。

## 6. 验收清单（AD，逐条打勾）

| 编号 | 验收项 |
| --- | --- |
| AD-1 | 双击单词弹卡，位置在词附近（≤8px 锚定），点空白 / `Esc` / 滚动 / 开始输入均能关闭 |
| AD-2 | 单击定位光标**零误触**：连续写作 10 分钟、随意的单击不出现一次弹卡 |
| AD-3 | 划选 2–4 词弹短语卡（含例句、标注在线来源）；划选 ≥5 词不弹 |
| AD-4 | 高频词（ECDICT 命中）显示音标/词性/多条释义/考纲标签，感知 <100ms；生僻词自动转在线解释并标注"AI 生成，仅供参考" |
| AD-5 | 拼错的词能给出"可能是 XXX 的拼写错误"类提示 |
| AD-6 | 收藏后按钮变"✓ 已收藏 · 用过 N 次"；词表出现该词且原句 = **所在句**；重复收藏幂等 |
| AD-7 | 词形还原生效：双击 `recalled` 显示"go/recall 类"原形提示（以真实词形为准），且该判定与 FR-1202 再使用计数用**同一个**词形还原实现 |
| AD-8 | 400px 窄屏卡片不溢出视口；深色模式下对比度达标（NFR-9） |
| AD-9 | 查词不计翻译配额；在线解释超限（10 次/分钟）时卡内出现可读的"稍后再试"，不报 500 |
| AD-10 | 词表页搜索框同样弹卡；空 context 收藏允许，复习时退化为"词 → 释义"卡 |
| AD-11 | 三种触发模式在设置页可切换、刷新后保留；行为符合 §2.1/2.2——浮标模式下选中只出浮标、点浮标才弹卡；修饰键模式仅 Alt+划选触发；划选即弹模式替换式选中（选完立刻打字）不闪卡 |
| AD-12 | 词卡自动朗读开关生效：开启后弹卡即朗读，关闭后仅朗读按钮发声 |
